# FM-LiDAR pipeline 🔦

> Проект посвящен созданию пайплайна обработки вейвформ, получаемых при работе частотно-модулированного лидара.

Вейвформы подлежат спектральной фильтрации и нормировке для дальнейшего определения фундаментальной частоты, которая прямо пропорциональна дистанции, детектируемой прибором.

## Начало работы

1. 🐳 Запустите Docker-контейнер с DataJoint-MySQL сервером (см. [README.rst](/mysql-docker/README.rst))
2. 👤 Используя любой MySQL-клиент (напр. [Querym](https://github.com/querymx/querym.git)), создайте нового пользователя и запишите учетные данные в [конфиг](/dj_local_conf.json)
3. ▶️ Запустите [main.py](/main.py) для демонстрации функционала пайплайна

## Структура пайплайна
